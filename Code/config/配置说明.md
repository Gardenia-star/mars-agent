# MARS-Agent 配置文件说明

## 模型权重路径配置

项目中的模型权重文件统一存放在 `weights/` 目录下：

- **YOLO检测模型**: `weights/best.pt`
- **ResNet分类模型**: `weights/resnet18_fireeye_3cls.pth`

代码中已自动配置为相对路径，无需手动修改。

## 检测参数配置

在 `qt_interface/algo_fireeye.py` 和 `web_interface/algo_fireeye.py` 中：

```python
# 图像尺寸
IMG_SIZE = 224

# 置信度阈值
CONF_EYE = 0.18      # 火眼检测置信度
CONF_FIRE = 0.15     # 火焰检测置信度

# 目标过滤
MIN_SIDE = 20        # 最小目标边长（像素）
IOU_MERGE = 0.5      # IoU合并阈值

# 分类平滑
K_SMOOTH = 5         # 平滑窗口大小
SWITCH_THR = 0.8     # 类别切换阈值
```

## 大模型配置

### Ollama本地模型

在 `llm_service.py` 和 `llm_web.py` 中：

```python
model_name = "llava"  # 默认使用llava模型
```

支持的模型（需先通过ollama下载）：
- `llava` - 多模态视觉语言模型（推荐）
- `llava:13b` - 更大参数版本
- `bakllava` - 另一个视觉模型选项

## 视频源配置

### PyQt界面

默认视频路径已设为空，需用户手动选择。

支持的视频源：
- 本地视频文件（MP4, AVI, MKV等）
- USB摄像头（ID: 0, 1, 2...）
- RTSP网络流（rtsp://...）
- HTTP视频流（http://...）

### Web界面

仅支持上传图片文件（JPG, PNG, BMP等）

## 历史记录配置

历史记录文件：`qt_interface/history_record.json`

可配置项：
- 最大保存记录数
- 记录保存路径
- 快照图片保存路径

## 网络端口配置

### Streamlit Web服务

默认端口：`8501`

修改端口：
```bash
streamlit run streamlit_app.py --server.port 8502
```

### Ollama服务

默认端口：`11434`

如需修改Ollama端口，需在代码中指定：
```python
import ollama
ollama.Client(host='http://localhost:11434')
```

## GPU/CPU配置

默认自动检测并优先使用GPU。

强制使用CPU：
在 `algo_fireeye.py` 中修改：
```python
# 找到类似这样的代码
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# 改为
device = torch.device('cpu')
```
