## 安装步骤（给接收者）

```bash
# 1. 解压项目文件
unzip Mars_Agent.zip
cd Mars_Agent

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动应用
# Windows: 双击 启动QT界面.bat 或 启动Web界面.bat
# Linux/Mac: bash 启动QT界面.sh 或 bash 启动Web界面.sh
```

## 可选功能

如需使用AI大模型分析功能，需额外安装Ollama：

```bash
# 安装Ollama
# Windows: 下载安装包 https://ollama.ai
# Linux: curl https://ollama.ai/install.sh | sh

# 拉取模型
ollama pull llava

# 启动服务
ollama serve
```
