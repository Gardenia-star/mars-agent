# 示例视频和测试数据说明

## 测试视频

由于权重文件较大，示例视频未包含在此目录中。

### 获取测试视频

1. **使用自己的视频**：
   - 铝电解槽火眼监控视频
   - 格式：MP4, AVI, MKV等
   - 分辨率：建议640x480以上

2. **使用摄像头**：
   - 启动程序后选择摄像头ID（0, 1, 2...）
   - 实时检测

### 测试图片

Web界面支持上传静态图片进行测试：
- 格式：JPG, PNG, BMP
- 尺寸：不限（会自动缩放）
- 内容：包含火眼或火焰区域的图像

## 数据集说明

本项目使用的训练数据集未包含在发布版本中。

如需训练自己的模型，数据集应包含：
- 火眼区域标注（YOLO格式）
- 三分类标签（C/N/H）
- 建议数据量：1000+ 标注图片

## 注意事项

- 请不要上传包含敏感信息的工业现场视频
- 测试时建议先使用低分辨率视频验证功能
- 首次运行会加载模型，需要等待几秒钟
