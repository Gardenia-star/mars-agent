## 🚀 使用方式（给接收者）

### 第一步：安装依赖
```bash
cd Mars_Agent
pip install -r requirements.txt
```

### 第二步：启动应用

**方式1：PyQt5 桌面界面**
- Windows: 双击 `启动QT界面.bat`
- Linux/Mac: `bash 启动QT界面.sh`

**方式2：Streamlit Web界面**
- Windows: 双击 `启动Web界面.bat`
- Linux/Mac: `bash 启动Web界面.sh`

### 第三步（可选）：安装AI大模型
```bash
# 安装 Ollama
# 拉取 Llava 模型
ollama pull llava
# 启动服务
ollama serve
```

## ⚙️ 核心技术

- **深度学习框架**: PyTorch

## ⚠️ 注意事项

1. **首次运行需要安装依赖** - 约需3-5分钟
2. **权重文件较大** - 确保网络传输时不要损坏
3. **AI功能可选** - 不安装Ollama也能正常使用基础功能
4. **GPU推荐** - CPU也能运行，但速度较慢
